encrypt-text-online
🔐 Encrypt Text Online Aplicación web para cifrar y descifrar texto directamente desde el navegador.
Incluye una landing estática y una SPA desarrollada con React + Vite. ---

🚀 Características principales
Cifrado y descifrado de texto en el navegador (sin enviar datos a servidores).
Interfaz rápida y ligera gracias a React + Vite.
Landing page independiente accesible desde la raíz del proyecto.
SPA accesible desde /app.
Build optimizado para GitHub Pages.
Extracción de texto de PDFs sin necesidad de renderizarlos.
Despliegue automático en la rama gh-pages
