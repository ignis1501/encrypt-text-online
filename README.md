🔐 Cifrar Archivos y Texto Online — Herramientas de Encriptación Gratis y Segura

Bienvenido al repositorio del proyecto Cifrar Archivos Online y Cifrar Texto Online, una herramienta web rápida, segura y totalmente gratuitas para proteger tu información mediante cifrado moderno.
Esta herramienta funciona directamente en tu navegador, sin subir tus datos a ningún servidor.

👉 Web del proyecto:  
https://ignis1501.github.io/encrypt-text-online/
🚀 ¿Qué puedes hacer con esta herramienta?

    Cifrar archivos online  
    Protege documentos PDF, imágenes, ZIP, vídeos y cualquier archivo mediante cifrado AES‑256.

    Cifrar texto online  
    Encripta mensajes, notas, contraseñas o cualquier texto sensible.

    Todo ocurre en tu navegador  
    No se envía nada a servidores externos.
    100% privacidad. 100% seguridad.

🛡️ Seguridad y privacidad

    Cifrado AES‑256‑GCM, estándar moderno y seguro.

    Procesamiento local en el navegador.

    No se almacenan datos.

    Código abierto y auditable.

⚙️ Tecnologías utilizadas

    React + Vite para la aplicación principal

    TypeScript

    GitHub Pages para el hosting

    Counter.dev para analítica sin cookies

    Web Crypto API para el cifrado real en el navegador
